## Overview

Capstone project (2014) for the Java Enterprise Software Engineer Program at the Institute for Information Industry (III). I led the project team and built a stock trading simulation web app.

## Core features

- Real-time stock price crawler (using JNA)
- Order placement and matching engine
- Chart visualization (Highcharts)
- Data management screens (DataTables)

## Highlights

- Built on the MVC design pattern
- Researched and integrated several third-party libraries on my own
- Full frontend-to-backend integration experience

## Tech stack

Java, Spring, Hibernate, jQuery, Highcharts, DataTables
