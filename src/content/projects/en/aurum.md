## Overview

A membership-based fund management platform that I built entirely on my own, covering requirements, architecture, database schema, backend APIs, frontend UI and deployment.

- **Role**: Solo Founder / Full-Stack Engineer
- **Timeline**: 2026/01 – 2026/02

## AI-assisted workflow

Claude Code served as my core development partner. I used MCP to connect Stitch for frontend design and Chrome DevTools MCP for UI interaction testing, with custom Skills to keep code quality and the Gitflow process consistent. This let me deliver 17 business modules on my own in two months.

## Tech stack

- **Backend**: Java 21 / Spring Boot 3.2 / MyBatis-Plus / Sa-Token / Redis
- **Frontend**: Vue 3 / TypeScript / Element Plus
- **Infrastructure**: MySQL 8 / Redis / Docker Compose

## Scale

- 17 business modules, 3 independent services (App API / Admin API / Job)
- Core features: crypto deposit and withdrawal (TRC20/ERC20), membership tiers, yield products, revenue-sharing calculation, RBAC admin console
