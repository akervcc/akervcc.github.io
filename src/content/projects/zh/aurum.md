## 專案概要

獨立完成一套會員制資金管理平台，從需求規劃、架構設計、資料庫 Schema、後端 API、前端 UI 到部署上線全程一手包辦。

- **個人角色**：Solo Founder / Full-Stack Engineer
- **開發期間**：2026/01 – 2026/02

## AI 輔助開發流程

以 Claude Code 為核心開發夥伴，透過 MCP 串接 Stitch 產出前端設計、用 Chrome DevTools MCP 進行 UI 互動驗證，並以自訂 Skills 維持程式碼品質與 Gitflow 流程，兩個月內以一人之力完成 17 個業務模組。

## 技術棧

- **後端**：Java 21 / Spring Boot 3.2 / MyBatis-Plus / Sa-Token / Redis
- **前端**：Vue 3 / TypeScript / Element Plus
- **基礎設施**：MySQL 8 / Redis / Docker Compose

## 專案規模

- 17 個業務模組、3 個獨立服務（App API / Admin API / Job）
- 核心功能：加密貨幣充提整合（TRC20/ERC20）、會員分級、收益產品、分潤計算、RBAC 權限管理後台
